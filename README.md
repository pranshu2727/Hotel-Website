# 🏨 Hotel BT — Responsive Hotel Website

A responsive hotel website built using **HTML5 and CSS3**. The project provides a clean and simple interface for visitors to explore the hotel, learn about its history, read guest reviews, and get in touch through a contact form.

## 🌐 Live Preview

`https://app.netlify.com/projects/hoteldjango/overview`

## 📌 About the Project

**Hotel BT** is a multi-page hotel website designed to provide a simple and user-friendly browsing experience.

The website consists of three main pages:

* **Home** — Hotel introduction, highlights, and facilities
* **About** — Hotel information and guest reviews
* **Contact** — Contact form and hotel contact information

The website is also designed to be **responsive**, with a separate CSS file for mobile devices.

## ✨ Features

* Responsive navigation bar
* Attractive hero section with hotel imagery
* Hotel introduction and history section
* Hotel facilities section
* Guest reviews section
* Contact form

## 📱 Responsive Design

The website uses a dedicated `mobile.css` stylesheet for screens smaller than **768px**.

On mobile devices:

* Navigation elements are stacked vertically
* The logo is centered
* The hero content adapts to the smaller screen
* The hotel information image is hidden
* Content sections become full-width
* Facility cards are stacked vertically
* About page content is adjusted for smaller screens

## 🚀 How to Run the Project

No additional dependencies or installation are required.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/hotel-bt.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd hotel-bt
```

### 3. Run the website

Open `home.html` in your web browser.

You can also use **Live Server** in VS Code for a better development experience.

## 🎨 Design

The website uses a simple hotel-themed color palette:

* Dark gray for navigation and footer
* Light orange for highlights and feature sections
* White for text and content areas

The design focuses on **simplicity, readability, and responsive layout** rather than complex animations or frameworks.
